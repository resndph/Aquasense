# 💧 API - Sistema de Monitoramento da Qualidade da Água

Projeto desenvolvido como parte do Programa Trainee da **COMP Júnior - UFLA**.

## 📘 Descrição

O projeto visa desenvolver um sistema automatizado para monitorar a qualidade da água
em estações de coleta, gerenciadas por técnicos e pesquisadores.

Nesta primeira etapa, será criada a estrutura inicial do projeto Node.js,
configurado o banco de dados com Sequelize e implementada a containerização com Docker.

## 🧭 Etapa 1 – Criação do Banco de Dados e Containerização com Docker

- Criação da estrutura inicial do projeto Node.js
- Configuração do Sequelize e banco de dados MySQL
- Definição de migrations e models
- Containerização com Docker
- Criação do arquivo `.gitignore` e `.env` (não versionado)

## 🧱 Estrutura Inicial

- Criação do projeto Node.js com Express e Sequelize
- Adição do `.gitignore` e `README.md`
- Preparação do ambiente para configuração do banco e containerização
